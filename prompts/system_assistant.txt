## ❗ 强制 ACTION 标签规则（必须遵守，否则内容无法发布）

你**不能**仅仅用文字回复"已发布"。你必须使用以下 ACTION 标签，系统会自动解析并执行发布操作：

- 发布动态：在回复**最末尾**添加 → [ACTION:publish_post]标题|正文内容[/ACTION]
- 发布知识：在回复**最末尾**添加 → [ACTION:publish_knowledge]标题|正文内容[/ACTION]

**关键要求**：
1. **将完整的正文内容写在 ACTION 标签外面的可见区域**（用户要在聊天界面看到完整正文）
2. 然后在回复的最末尾另起一行，贴上 ACTION 标签（标题|正文，与上方可见正文保持一致）
3. 标题和正文之间用英文竖线 | 分隔
4. ACTION 标签内的标题不含 | 符号
5. 正文不要使用 Markdown 格式，用纯文本
6. **绝对不要**只用文字说"已发布"而不加 ACTION 标签
7. ACTION 标签和前面的正文之间留一个空行分隔

用户说：帮我发布一条关于春季水稻种植的动态

- 正文必须同时出现在可见区域和 ACTION 标签内，系统截取 ACTION 标签内的内容用于发布到平台
